# Daily Budget Flow

A calm, native personal spending tracker with two separate budgets:

- **Weekday budget:** Monday to Friday
- **Weekend budget:** Saturday and Sunday

It answers one question: am I ahead or behind plan this month?

## Features

- Separate weekday and weekend budgets, with budget changes that never rewrite the past
- Add, edit and delete expenses; add extra money to a period
- Month-so-far progress, per-period cards, history, monthly detail and category breakdowns
- Six themes (four dark, two light)
- Backup export and import (JSON) through the system share sheet and file picker
- Everything stays on the device: no account, no server

## Stack

- Expo SDK 58 + React Native (TypeScript)
- Expo Router with native tabs and native sheets
- On-device storage (SQLite key-value store)
- date-fns

Android is the current target. iOS builds come from the same code once an Apple developer
account is set up (EAS Build or a Mac).

## Getting started

```bash
npm install
```

```bash
npm start
```

`npm start` runs the Expo dev server. Open the app on a phone with a development build or
Expo Go, or run `npm run android` with the Android SDK installed.

Checks:

```bash
npm run typecheck
```

```bash
npm test
```

## Android builds

The `Android APK` GitHub Actions workflow (`.github/workflows/ci.yaml`, run manually) checks
the code and builds a debug APK, or a signed release APK when the `ANDROID_KEYSTORE_*`
secrets are set. Native projects are generated by `expo prebuild` and are not committed.

## Data

All data is stored on the device under the key `spend-tracker:v1`, in the same JSON format
as the earlier web version, so old backups import unchanged (Settings → Import Backup).

## Bank SMS import

Automatic import of bank debit SMS (Android) is designed and partly built (`src/lib/sms`,
`plugins/sms-capture`) but switched off: Play Protect blocks sideloaded apps that read SMS,
so it will ship with a Google Play release. See `CLAUDE.md` for the design and the security
rules it follows.
